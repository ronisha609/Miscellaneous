# First VS Code Project | HTML & CSS Foundations

An early page-building lab that assembles navigation links, form fields, images, and styling across local project files.

## Capabilities Demonstrated

- Organize HTML pages, image assets, and stylesheets.
- Trace how links and file paths connect project resources.
- Build basic form and navigation elements.
- Recognize how document structure and stylesheet references affect rendering.

## Project Files

[Main page](index.html) · [About page](about.html) · [Stylesheet](resources/css/style.css)

## Learning Context

Preserved as an early practice sample. The main page includes malformed markup, an incomplete stylesheet reference, and placeholder form actions. It preserves source material for code inspection and correction rather than claiming a finished login system or deployed website.
