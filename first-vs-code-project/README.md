# First VS Code Project | HTML & CSS Foundations

Early page-building practice exploring navigation links, form fields, images, and styling across local project files.

## Skills & Learning Outcomes

- Organize HTML pages, image assets, and stylesheets.
- Understand how links and file paths connect project resources.
- Build basic form and navigation elements.
- Recognize how document structure and stylesheet references affect rendering.

## Explore the Files

[Main page](index.html) · [About page](about.html) · [Stylesheet](resources/css/style.css)

## Learning Context

Preserved as an early practice sample. The main page includes malformed markup, an incomplete stylesheet reference, and placeholder form actions. It demonstrates learning material to inspect and improve rather than a finished login system or deployed website.
