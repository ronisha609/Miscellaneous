# Quote Generator | Fetch & DOM Integration

An early JavaScript exercise that requests quote data, selects a random entry, and writes the quote and author into the page.

## Capabilities Demonstrated

Fetch API, async/await, JSON parsing, arrays, random selection, and DOM updates.

## Review Notes

The code depends on an external quote endpoint whose availability was not tested. Its missing-author branch attempts to reassign a `const` variable, and it has no request-error handling. This is an archived implementation with documented gaps.
