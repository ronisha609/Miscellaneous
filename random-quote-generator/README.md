# Random Quote Generator | API & JavaScript Practice

A browser exercise that separates requesting quote data from selecting a quote to display. The source includes earlier approaches as comments alongside asynchronous request and selection functions.

## Skills & Learning Outcomes

- Use async functions and await an HTTP response.
- Check response status and parse JSON data.
- Select an item from an array and update page content.
- Explore try/catch and consider how a failed request affects later code.

[JavaScript](app.js) · [Page markup](index.html) · [Styles](styles.css)

## Learning Context

An early practice implementation. The external quote API and browser behavior were not tested during this documentation update. Learners can review what happens when a request returns no usable data before the selection function runs.
