# Fetch API | Request & Response Exercise

A guided JavaScript exercise intended to request user data and inspect the response. The current source is a scaffold: the fetch argument and response handlers still need implementation.

## Capabilities Demonstrated

- Trace how a URL enters and drives a request.
- Convert a response into JSON.
- Work with promise chains and error handling.
- Inspect returned data in the browser console.

[Read the scaffold](app.js) before following the original task below. These are exercise objectives, not claims of a working integration. The external endpoint was not tested in this review.

## Original Exercise Instructions

# Fetch Practice Exercise


You will be using your fetch skills in this exercise!

Your objective is to display the user data from <a href='https://reqres.in/api/users' target="_blank">this url</a>!

How and what you display to the console is up to you, you may display just names, names and emails, names and avatars, whatever you deem fit.
The only requirement is that you must display something that you retrieved from the above url.

You will have 30 minutes to complete this activity.
